# LifePlan Pro

Native macOS planner dashboard built with SwiftUI. The app uses a dark/purple visual system, task/event/project/goal/notes planning, local persistence, and a time-aware scenic header that changes between morning, day, sunset, and night.

## Build

Run `./scripts/build_app.sh` on macOS 13+ with Xcode Command Line Tools, or use the included GitHub Actions workflow to produce `LifePlan Pro.app` as a downloadable artifact.
